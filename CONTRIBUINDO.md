# Como contribuir

Contribuições são bem-vindas! Para sugerir melhorias ou relatar problemas, abra uma issue descrevendo sua proposta.

1. Faça um fork do repositório e crie uma branch para sua alteração.
2. Realize mudanças pequenas e claras, revisando a documentação e verificando o funcionamento quando aplicável.
3. Faça um commit com uma mensagem descritiva e envie sua branch ao GitHub.
4. Abra um Pull Request para a branch `main`, explicando o que mudou e como você verificou a alteração.

Mantenha uma comunicação respeitosa e esteja disponível para ajustar sua contribuição após a revisão.
